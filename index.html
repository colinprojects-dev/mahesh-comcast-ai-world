Model options and security boundaries

LRN1132 explicitly discusses BYOLLM within sovereign AI infrastructure. It does not establish support in embedded Fusion AI or AI Agent Studio. THR6097 covers private AI Database/container architecture, private inference and RAG; it is an Adjacent technical option. Private inference, retrieval over data, model customization, external endpoint integration and customer-provided model hosting are distinct.

Fusion/Agent Studio approved-model choices, external endpoint support, release restrictions, entitlements, data retention/residency and the security consequences of a specific design remain appropriate expert follow-ups. No model is assumed approved, and selecting a model does not automatically settle data security. Oracle Integration sessions describe governed connections and actions, not universal model replacement.
